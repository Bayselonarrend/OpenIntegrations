# PerformSearch
 Perform LDAP search



<Tabs>
  <TabItem value="params" label="Parameters" default>

`Function PerformSearch(Val Connection, Val Base, Val Filter = "(objectClass=*)", Val Attributes = Undefined, Val Region = "subtree") Export`

  | Parameter | CLI option | Type | Required | Description |
  |-|-|-|-|-|
  | Connection | --conn | Arbitrary, Structure Of KeyAndValue | &#x2714; | Connection or connection parameters |
  | Base | --base | String | &#x2714; | Base search DN |
  | Filter | --filter | String | &#x2716; | LDAP filter |
  | Attributes | --attrs | Array of String, Undefined | &#x2716; | List of attributes for selection |
  | Region | --scope | String | &#x2716; | Scope: base, one, subtree |


<div className="return-value-note">

:::tip
When passing connection parameters, a new connection will be created and closed within one call
:::
<br/>


```bsl title="1C:Enterprise/OneScript code example"
    URL      = "ldap://127.0.0.1:389";
    BindDN = "cn=admin,dc=example,dc=org";
    Password = "a...";
    Timeout  = 30;

    ConnectionParams = OPI_LDAP.FormConnectionParameters(URL, BindDN, Password, Timeout);
    Connection       = OPI_LDAP.CreateConnection(ConnectionParams);
    Base = "dc=example,dc=org";
    Filter = "(objectClass=*)";

    Result = OPI_LDAP.PerformSearch(Connection, Base, Filter);
```
