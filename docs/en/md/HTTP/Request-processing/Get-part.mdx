# Get part 
 Sends a request to retrieve data with the Range header



<Tabs>
  <TabItem value="params" label="Parameters" default>

`Function GetPart(Val StartPosition, Val ByteCount, Val Method = "GET") Export`

  | Parameter | CLI option | Type | Required | Description |
  |-|-|-|-|-|
  | StartPosition | - | Number | &#x2714; | Position from which to retrieve data |
  | ByteCount | - | Number | &#x2714; | Size of the data to retrieve in bytes |
  | Method | - | String | &#x2716; | Request HTTP method |

```bsl title="1C:Enterprise/OneScript code example"
    URL = "https://bin.openintegrations.dev";
    URL = URL + "/range/100";

    // Get bytes 0-9
    StartPosition = 0;
    Bytes = 10;

    Result = OPI_HTTPRequests.NewRequest()
        .Initialize(URL)
        .GetPart(StartPosition, Bytes) // <---
        .ReturnResponse();
```
