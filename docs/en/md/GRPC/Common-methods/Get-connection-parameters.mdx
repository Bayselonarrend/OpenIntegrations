# Get connection parameters
 Forms a structure of parameters for creating a connection



<Tabs>
  <TabItem value="params" label="Parameters" default>

`Function GetConnectionParameters(Val Address, Val Proto = Undefined, Val Metadata = Undefined, Val UserAgent = "", Val Compression = "", Val MaxResponseSize = 0, Val MaxRequestSize = 0, Val ConnectionTimeout = 10000) Export`

  | Parameter | CLI option | Type | Required | Description |
  |-|-|-|-|-|
  | Address | --addr | String | &#x2714; | Connection address (with protocol) |
  | Proto | --proto | Arbitrary | &#x2716; | Schema or schema structure: Key > file name (for import), Value > schema as a string or file path |
  | Metadata | --meta | Structure Of KeyAndValue | &#x2716; | Metadata structure, if necessary |
  | UserAgent | --ua | String | &#x2716; | User Agent of the channel. An empty string leaves the default value |
  | Compression | --compress | String | &#x2716; | Compression of requests and responses: gzip or empty string |
  | MaxResponseSize | --maxresp | Number | &#x2716; | Maximum size of incoming message in bytes. 0 leaves the default limit |
  | MaxRequestSize | --maxreq | Number | &#x2716; | Maximum size of outgoing message in bytes. 0 leaves the default limit |
  | ConnectionTimeout | --ctout | Number | &#x2716; | Connection timeout in milliseconds. 0 removes the restriction |

:::tip
Proto file name is used to allow further specification of this Proto in the import of another Proto It does not have to be a real file path. Proto files that are not involved in the import of other Protos can have arbitrary file names

If the Proto value is not an object (a key value collection), it will be interpreted as `{"main.proto": passed value}` User-Agent of the channel is taken from the UserAgent parameter, and if it is not filled - from the `user-agent` metadata of this set. The version tonic is appended to it. The metadata set after opening the connection, User-Agent of the channel does not change. Compression takes the value `gzip` or an empty string. Message sizes are set in bytes. Connection timeout limits the setup of TCP and TLS. A value of 0 removes the restriction, with a default of 10000 ms. CallTimeout includes waiting for the channel to be ready
:::

```bsl title="1C:Enterprise/OneScript code example"
    Address = "https://grpcb.in:9001";

    Proto1 = "https://hut.openintegrations.dev/test_data/grpcbin_with_import.proto"; // String, path to file or URL
    Proto2 = "https://hut.openintegrations.dev/test_data/mt.proto"; // String, path to file or URL

    Scheme = New Map;
    Scheme.Insert("main.proto"    , Proto1); // Primary
    Scheme.Insert("my_types.proto", Proto2); // For import in primary

    Meta   = New Structure("somekey", "somevalue");
    Result = OPI_GRPC.GetConnectionParameters(Address, Scheme, Meta);
```
