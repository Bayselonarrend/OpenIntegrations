# Получить параметры соединения
 Формирует структуру параметров для создания соединения



<Tabs>
  <TabItem value="params" label="Параметры" default>

`Функция ПолучитьПараметрыСоединения(Знач Адрес, Знач Proto = Неопределено, Знач Метаданные = Неопределено, Знач UserAgent = "", Знач Сжатие = "", Знач МаксимальныйРазмерОтвета = 0, Знач МаксимальныйРазмерЗапроса = 0, Знач ТаймаутПодключения = 10000) Экспорт`

  | Параметр | CLI опция | Тип | Обяз. | Назначение |
  |-|-|-|-|-|
  | Адрес | --addr | Строка | &#x2714; | Адрес для подключения (с протоколом) |
  | Proto | --proto | Произвольный | &#x2716; | Схема или структура схем: Ключ > имя файла (для import), Значение > схема строкой или путь к файлу |
  | Метаданные | --meta | Структура Из КлючИЗначение | &#x2716; | Структура метаданных, если необходимо |
  | UserAgent | --ua | Строка | &#x2716; | User Agent канала. Пустая строка оставляет значение по умолчанию |
  | Сжатие | --compress | Строка | &#x2716; | Сжатие запросов и ответов: gzip или пустая строка |
  | МаксимальныйРазмерОтвета | --maxresp | Число | &#x2716; | Максимальный размер входящего сообщения в байтах. 0 оставляет предел по умолчанию |
  | МаксимальныйРазмерЗапроса | --maxreq | Число | &#x2716; | Максимальный размер исходящего сообщения в байтах. 0 оставляет предел по умолчанию |
  | ТаймаутПодключения | --ctout | Число | &#x2716; | Таймаут установки соединения в миллисекундах. 0 снимает ограничение |

:::tip
Имя файла Proto используется для возможности дальнейшего указания этого Proto в import другого Proto Оно не обязано являться настоящим путем к файлу. Proto, не участвующие в import других Proto, могут иметь произвольное имя файла

Если значение Proto не является объектом (коллекцией ключ и значение), то оно будет интерпретировано как `{"main.proto": переданное значение}` User-Agent канала берется из параметра UserAgent, а если он не заполнен - из ключа `user-agent` метаданных этого набора. К нему дописывается версия tonic. Метаданные, установленные после открытия соединения, User-Agent канала не меняют. Сжатие принимает значение `gzip` или пустую строку. Размеры сообщений задаются в байтах. Таймаут подключения ограничивает установку TCP и TLS. Значение 0 снимает ограничение, по умолчанию 10000 мс. Таймаут вызова метода включает ожидание готовности канала
:::

```bsl title="Пример использования для 1С:Предприятие/OneScript"
    Адрес = "https://grpcb.in:9001";

    Proto1 = "https://hut.openintegrations.dev/test_data/grpcbin_with_import.proto"; // Строка, путь к файлу или URL
    Proto2 = "https://hut.openintegrations.dev/test_data/mt.proto";     // Строка, путь к файлу или URL

    Схемы = Новый Соответствие;
    Схемы.Вставить("main.proto"    , Proto1); // Основной
    Схемы.Вставить("my_types.proto", Proto2); // Для импорта в основной

    Мета      = Новый Структура("somekey", "somevalue");
    Результат = OPI_GRPC.ПолучитьПараметрыСоединения(Адрес, Схемы, Мета);
```
