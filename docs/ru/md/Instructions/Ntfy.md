## Начало работы

Ntfy — это простой сервис для отправки уведомлений на телефоны, веб-браузеры и другие устройства. Вы можете использовать:

1. **Публичный сервер** `ntfy.sh` — бесплатный, без регистрации, но с ограничениями
2. **Собственный сервер** Ntfy — полный контроль и отсутствие ограничений

### Использование публичного сервера

Для работы с `ntfy.sh` достаточно выбрать уникальное имя топика:

```bsl
Топик = "мой_уникальный_топик_123";
Сообщение = "Привет из 1С!";

Результат = OPI_Ntfy.ОтправитьСообщение("", Топик, Сообщение);
```

:::important
При использовании публичного сервера выбирайте уникальное имя топика, чтобы избежать пересечений с другими пользователями
:::

### Использование собственного сервера

Если вы развернули собственный сервер Ntfy, укажите его URL:

```bsl
URL = "https://ntfy.example.com";
Топик = "важные_уведомления";
Сообщение = "Сообщение с собственного сервера";

Результат = OPI_Ntfy.ОтправитьСообщение(URL, Топик, Сообщение);
```

### Защита топиков токеном

Для защищённых топиков используйте токен доступа:

```bsl
Токен = "tk_ваш_токен_доступа";
Результат = OPI_Ntfy.ОтправитьСообщение(URL, Топик, Сообщение, Токен);
```

## Отправка уведомлений

### Простое уведомление

Базовая отправка уведомления требует только топик и текст сообщения:

```bsl
Топик = "новости";
Сообщение = "Новое обновление доступно!";

Результат = OPI_Ntfy.ОтправитьСообщение("", Топик, Сообщение);
```

### Уведомление с параметрами

Для расширенных возможностей используйте дополнительные параметры:

```bsl
Параметры = OPI_Ntfy.ПолучитьСтруктуруПараметровСообщения(Истина);
Параметры["Title"] = "Важное уведомление";
Параметры["Priority"] = "high";
Параметры["Tags"] = "warning,urgent";
Параметры["Click"] = "https://example.com";
Параметры["Icon"] = "https://example.com/icon.png";

Результат = OPI_Ntfy.ОтправитьСообщение("", Топик, Сообщение, "", Параметры);
```

### Доступные параметры уведомления

`ПолучитьСтруктуруПараметровСообщения` возвращает структуру со следующими полями:

- **Title** — заголовок уведомления
- **Priority** — приоритет: `min`, `low`, `default`, `high`, `max` или число от 1 до 5
- **Tags** — теги или эмодзи (строка или массив строк)
- **Click** — URL, открываемый при клике на уведомление
- **Attach** — URL вложения (изображение, файл)
- **Actions** — кнопки действий в формате Ntfy
- **Delay** — отложенная отправка (например, `10m` или unix timestamp)
- **Email** — email для пересылки уведомления
- **Icon** — URL иконки уведомления
- **Markdown** — `Истина` для форматирования текста как Markdown

```bsl
Параметры = OPI_Ntfy.ПолучитьСтруктуруПараметровСообщения(Истина);
Параметры["Title"] = "Отчёт готов";
Параметры["Priority"] = "high";
Параметры["Tags"] = Новый Массив;
Параметры["Tags"].Добавить("chart");
Параметры["Tags"].Добавить("money");
Параметры["Attach"] = "https://example.com/report.pdf";
Параметры["Markdown"] = Истина;

Сообщение = "**Ежемесячный отчёт** готов к просмотру!";
Результат = OPI_Ntfy.ОтправитьСообщение("", "отчеты", Сообщение, "", Параметры);
```

:::tip
Используйте теги-эмодзи для визуального выделения уведомлений: `warning`, `tada`, `fire`, `bell` и другие из списка [docs.ntfy.sh/emojis](https://docs.ntfy.sh/emojis/)
:::

## Получение сообщений

### Получение всех сообщений топика

```bsl
Топик = "новости";
Сообщения = OPI_Ntfy.ПолучитьСообщения("", Топик);
```

### Фильтрация сообщений

Используйте параметры фильтра для выборочного получения сообщений:

```bsl
Фильтр = OPI_Ntfy.ПолучитьСтруктуруПараметровФильтра(Истина);
Фильтр["since"] = "ID_последнего_полученного_сообщения";
Фильтр["limit"] = "10";

Сообщения = OPI_Ntfy.ПолучитьСообщения("", Топик, "", Фильтр);
```

### Доступные параметры фильтра

`ПолучитьСтруктуруПараметровФильтра` возвращает структуру с полями:

- **since** — ID сообщения, начиная с которого получить историю
- **poll** — `Истина` для long polling (ожидание нового сообщения)
- **limit** — максимальное количество возвращаемых сообщений

```bsl
Фильтр = OPI_Ntfy.ПолучитьСтруктуруПараметровФильтра(Истина);
Фильтр["poll"] = Истина; // Ожидать новое сообщение
Фильтр["limit"] = "1";

НовоеСообщение = OPI_Ntfy.ПолучитьСообщения("", Топик, Токен, Фильтр);
```

:::note
При использовании `poll = Истина` запрос будет ожидать появления нового сообщения в топике
:::

## Удаление сообщений

Удаление сообщений возможно только для **защищённых топиков** с токеном доступа:

```bsl
URL = "https://ntfy.example.com";
Топик = "защищенный_топик";
IDСообщения = "abc123def456";
Токен = "tk_ваш_токен";

Результат = OPI_Ntfy.УдалитьСообщение(URL, Топик, IDСообщения, Токен);
```

:::important
Удаление сообщений работает только для топиков, защищённых токеном. На публичном сервере ntfy.sh эта функция недоступна без настройки авторизации
:::

## Типичный сценарий

Пример комплексного использования библиотеки:

```bsl
// 1. Отправка уведомления с параметрами
Топик = "система_мониторинга";

Параметры = OPI_Ntfy.ПолучитьСтруктуруПараметровСообщения(Истина);
Параметры["Title"] = "Ошибка в системе";
Параметры["Priority"] = "urgent";
Параметры["Tags"] = "warning,computer";
Параметры["Email"] = "admin@example.com";

Сообщение = "Обнаружена критическая ошибка в модуле обработки данных";
Результат = OPI_Ntfy.ОтправитьСообщение("", Топик, Сообщение, "", Параметры);

// 2. Получение последних сообщений
Фильтр = OPI_Ntfy.ПолучитьСтруктуруПараметровФильтра(Истина);
Фильтр["limit"] = "5";

Сообщения = OPI_Ntfy.ПолучитьСообщения("", Топик, "", Фильтр);

// 3. Обработка полученных сообщений
Для Каждого Сообщение Из Сообщения Цикл
    Если Сообщение["priority"] = "urgent" Тогда
        // Обработка критических сообщений
    КонецЕсли;
КонецЦикла;
```

Подробности полей ответа, варианты CLI и примеры результатов — на страницах методов в разделах [Публикация](/docs/Ntfy/Publishing/Send-message), [Получение](/docs/Ntfy/Getting/Get-messages) и [Управление](/docs/Ntfy/Management/Delete-message).
