## Начало работы

Для работы с LDAP через библиотеку необходимо:

1. Получить URL LDAP-сервера (например, `ldap://dc.example.com:389` или `ldaps://dc.example.com:636`)
2. Подготовить учетные данные:
   - **Bind DN** — Distinguished Name пользователя для авторизации (например, `CN=admin,DC=example,DC=com`)
   - **Пароль** — пароль пользователя
3. Сформировать параметры соединения
4. Открыть соединение

```bsl
URL = "ldap://dc.example.com:389";
BindDN = "CN=admin,DC=example,DC=com";
Пароль = "password123";

ПараметрыСоединения = OPI_LDAP.СформироватьПараметрыСоединения(URL, BindDN, Пароль, 30);
Соединение = OPI_LDAP.ОткрытьСоединение(ПараметрыСоединения);
```

## Настройка соединения

### Базовое соединение

Для создания базового соединения достаточно указать URL сервера, Bind DN и пароль:

```bsl
ПараметрыСоединения = OPI_LDAP.СформироватьПараметрыСоединения(
    "ldap://dc.example.com:389",
    "CN=admin,DC=example,DC=com",
    "password123",
    30  // Таймаут в секундах
);

Соединение = OPI_LDAP.ОткрытьСоединение(ПараметрыСоединения);
```

### Защищенное соединение (LDAPS/TLS)

Для работы с LDAPS или StartTLS необходимо настроить TLS:

```bsl
// Настройка TLS
НастройкиTLS = OPI_LDAP.ПолучитьНастройкиTls(
    Истина,  // Отключить проверку сертификата (для самоподписанных)
    ""       // Путь к сертификату (необязательно)
);

Соединение = OPI_LDAP.ОткрытьСоединение(ПараметрыСоединения, НастройкиTLS);
```

### Соединение с логированием

Для отладки и мониторинга можно включить логирование:

```bsl
НастройкиЛога = OPI_LDAP.ПолучитьНастройкиЛогирования(
    Истина,  // Запись в память
    300,     // Максимум событий в памяти
    "C:\Logs\ldap.log"  // Путь к файлу лога (необязательно)
);

Соединение = OPI_LDAP.ОткрытьСоединение(ПараметрыСоединения, , НастройкиЛога);

// Получение лога
Лог = OPI_LDAP.ПолучитьЛог(Соединение, Истина, 100);
```

:::important
Рекомендуется явно закрывать соединение после завершения работы:
```bsl
OPI_LDAP.ЗакрытьСоединение(Соединение);
```
:::

## Поиск в каталоге

Метод `ВыполнитьПоиск` позволяет находить записи в LDAP-каталоге по заданным критериям.

### Базовый поиск

```bsl
База = "DC=example,DC=com";
Фильтр = "(objectClass=user)";

Результат = OPI_LDAP.ВыполнитьПоиск(Соединение, База, Фильтр);
```

### Поиск с выборкой атрибутов

```bsl
Атрибуты = Новый Массив;
Атрибуты.Добавить("cn");
Атрибуты.Добавить("mail");
Атрибуты.Добавить("telephoneNumber");

Результат = OPI_LDAP.ВыполнитьПоиск(Соединение, База, Фильтр, Атрибуты);
```

### Области поиска

Параметр `Область` определяет глубину поиска:

- **base** — только базовый объект
- **one** — непосредственные потомки базового объекта
- **subtree** — весь поддерево (по умолчанию)

```bsl
Результат = OPI_LDAP.ВыполнитьПоиск(Соединение, База, Фильтр, , "one");
```

### Автоматическое управление соединением

При передаче параметров соединения вместо объекта соединения, библиотека автоматически откроет и закроет соединение:

```bsl
Результат = OPI_LDAP.ВыполнитьПоиск(ПараметрыСоединения, База, Фильтр);
```

:::tip
Для множественных операций рекомендуется использовать открытое соединение — это повышает производительность
:::

## Модификация данных каталога

### Добавление записи

```bsl
DN = "CN=Новый Пользователь,OU=Users,DC=example,DC=com";

Атрибуты = Новый Структура;
Атрибуты.Вставить("objectClass", Новый Массив);
Атрибуты["objectClass"].Добавить("top");
Атрибуты["objectClass"].Добавить("person");
Атрибуты["objectClass"].Добавить("organizationalPerson");
Атрибуты["objectClass"].Добавить("user");

Атрибуты.Вставить("cn", "Новый Пользователь");
Атрибуты.Вставить("sn", "Пользователь");
Атрибуты.Вставить("mail", "user@example.com");

Результат = OPI_LDAP.Добавить(Соединение, DN, Атрибуты);
```

### Изменение записи

Для изменения записи нужно подготовить массив изменений. Каждое изменение — это структура с полями:
- **operation** — тип операции: `add`, `delete`, `replace`
- **attribute** — имя атрибута
- **values** — массив значений

```bsl
DN = "CN=Пользователь,OU=Users,DC=example,DC=com";

Изменения = Новый Массив;

// Изменить email
Изменение1 = Новый Структура;
Изменение1.Вставить("operation", "replace");
Изменение1.Вставить("attribute", "mail");
Изменение1.Вставить("values", Новый Массив);
Изменение1["values"].Добавить("newemail@example.com");
Изменения.Добавить(Изменение1);

// Добавить телефон
Изменение2 = Новый Структура;
Изменение2.Вставить("operation", "add");
Изменение2.Вставить("attribute", "telephoneNumber");
Изменение2.Вставить("values", Новый Массив);
Изменение2["values"].Добавить("+7 (999) 123-45-67");
Изменения.Добавить(Изменение2);

Результат = OPI_LDAP.Изменить(Соединение, DN, Изменения);
```

### Удаление записи

```bsl
DN = "CN=Удаляемый Пользователь,OU=Users,DC=example,DC=com";

Результат = OPI_LDAP.Удалить(Соединение, DN);
```

### Сравнение значения атрибута

Метод позволяет проверить, соответствует ли значение атрибута ожидаемому:

```bsl
DN = "CN=Пользователь,OU=Users,DC=example,DC=com";
Атрибут = "mail";
ОжидаемоеЗначение = "user@example.com";

Результат = OPI_LDAP.Сравнить(Соединение, DN, Атрибут, ОжидаемоеЗначение);
```
