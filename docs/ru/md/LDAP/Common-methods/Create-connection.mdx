# Открыть соединение 
 Открывает LDAP-соединение и выполняет bind



<Tabs>
  <TabItem value="params" label="Параметры" default>

`Функция ОткрытьСоединение(Знач ПараметрыСоединения, Знач Tls = Неопределено, Знач Логирование = Неопределено) Экспорт`

  | Параметр | CLI опция | Тип | Обяз. | Назначение |
  |-|-|-|-|-|
  | ПараметрыСоединения | - | Структура Из КлючИЗначение | &#x2714; | Параметры соединения. См. [`СформироватьПараметрыСоединения`](/docs/LDAP/Common-methods/Form-connection-parameters) |
  | Tls | - | Структура Из КлючИЗначение | &#x2716; | Настройки TLS, если необходимо. См. [`ПолучитьНастройкиTls`](/docs/LDAP/Common-methods/Get-tls-settings) |
  | Логирование | - | Структура Из КлючИЗначение | &#x2716; | Настройки логирования. См. [`ПолучитьНастройкиЛогирования`](/docs/LDAP/Common-methods/Get-logging-settings) |


<div className="return-value-note">
  <div className="return-value-note__title">Возвращаемое значение</div>
  <div className="return-value-note__value">
  Произвольный - Объект коннектора или структура с информацией об ошибке
  </div>
</div>
  
  </TabItem>
  <TabItem value="extended" label={<span>Расширенный вызов{' '}<a href="/docs/Start/Advanced-call" target="_blank" rel="noreferrer" title="Справка о расширенном вызове" onClick={(e) => e.stopPropagation()}>?</a></span>}>

  | Параметр | Описание |
  |---|---|
  | addin_mode | Ручной выбор режима подключения внешней компоненты (для 1С): Изолированно, НеИзолированно |


  </TabItem>
</Tabs>

```bsl title="Пример использования для 1С:Предприятие/OneScript"
    URL     = "";
    BindDN  = "cn=admin,dc=example,dc=org";
    Пароль  = "...";
    Таймаут = 30;

    ПараметрыСоединения = OPI_LDAP.СформироватьПараметрыСоединения(URL, BindDN, Пароль, Таймаут);
    Результат           = OPI_LDAP.ОткрытьСоединение(ПараметрыСоединения);
```
