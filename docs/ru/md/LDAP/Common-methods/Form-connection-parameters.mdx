# Сформировать параметры соединения
 Формирует коллекцию параметров LDAP-соединения



<Tabs>
  <TabItem value="params" label="Параметры" default>

`Функция СформироватьПараметрыСоединения(Знач URL, Знач BindDN = "", Знач Пароль = "", Знач Таймаут = 30) Экспорт`

  | Параметр | CLI опция | Тип | Обяз. | Назначение |
  |-|-|-|-|-|
  | URL | --url | Строка | &#x2714; | URL сервера (ldap: или ldaps:) |
  | BindDN | --bind | Строка | &#x2716; | DN для bind |
  | Пароль | --pass | Строка | &#x2716; | Пароль для bind |
  | Таймаут | --tout | Число | &#x2716; | Таймаут операций в секундах |


<div className="return-value-note">
  <div className="return-value-note__title">Возвращаемое значение</div>
  <div className="return-value-note__value">
  Структура Из КлючИЗначение - Структура параметров соединения
  </div>
</div>
  
  </TabItem>
  <TabItem value="extended" label={<span>Расширенный вызов{' '}<a href="/docs/Start/Advanced-call" target="_blank" rel="noreferrer" title="Справка о расширенном вызове" onClick={(e) => e.stopPropagation()}>?</a></span>}>

  | Параметр | Описание |
  |---|---|
  | addin_mode | Ручной выбор режима подключения внешней компоненты (для 1С): Изолированно, НеИзолированно |
  | dontwait | Создает фоновое задание и возвращает его данные (только для 1С и OneScript) |


  </TabItem>
</Tabs>



```bsl title="Пример использования для 1С:Предприятие/OneScript"
    URL     = "";
    BindDN = "cn=admin,dc=example,dc=org";
    Пароль  = "...";
    Таймаут = 30;

    Результат = OPI_LDAP.СформироватьПараметрыСоединения(URL, BindDN, Пароль, Таймаут);
```
