# ВыполнитьПоиск
 Выполняет LDAP-поиск



<Tabs>
  <TabItem value="params" label="Параметры" default>

`Функция ВыполнитьПоиск(Знач Соединение, Знач База, Знач Фильтр = "(objectClass=*)", Знач Атрибуты = Неопределено, Знач Область = "subtree") Экспорт`

  | Параметр | CLI опция | Тип | Обяз. | Назначение |
  |-|-|-|-|-|
  | Соединение | --conn | Произвольный, Структура Из КлючИЗначение | &#x2714; | Соединение или параметры соединения |
  | База | --base | Строка | &#x2714; | Базовый DN поиска |
  | Фильтр | --фильтр | Строка | &#x2716; | LDAP |
  | Атрибуты | --attrs | Массив Из Строка, Неопределено | &#x2716; | Список атрибутов для выборки |
  | Область | --scope | Строка | &#x2716; | Область: base, one, subtree |

:::tip
При передаче параметров соединения новое соединение будет создано и закрыто в рамках одного вызова
:::
<br/>


```bsl title="Пример использования для 1С:Предприятие/OneScript"
    URL     = "ldap://127.0.0.1:389";
    BindDN  = "cn=admin,dc=example,dc=org";
    Пароль  = "a...";
    Таймаут = 30;

    ПараметрыСоединения = OPI_LDAP.СформироватьПараметрыСоединения(URL, BindDN, Пароль, Таймаут);
    Соединение          = OPI_LDAP.ОткрытьСоединение(ПараметрыСоединения);
    База                = "dc=example,dc=org";
    Фильтр              = "(objectClass=*)";

    Результат = OPI_LDAP.ВыполнитьПоиск(Соединение, База, Фильтр);
```
