# Изменить
 Изменяет запись в каталоге LDAP



<Tabs>
  <TabItem value="params" label="Параметры" default>

`Функция Изменить(Знач Соединение, Знач DN, Знач Изменения) Экспорт`

  | Параметр | CLI опция | Тип | Обяз. | Назначение |
  |-|-|-|-|-|
  | Соединение | --conn | Произвольный, Структура Из КлючИЗначение | &#x2714; | Соединение или параметры соединения |
  | DN | --dn | Строка | &#x2714; | DN изменяемой записи |
  | Изменения | --changes | Массив Из Структура | &#x2714; | Список изменений атрибутов |


<div className="return-value-note">
  <div className="return-value-note__title">Возвращаемое значение</div>

  Соответствие Из КлючИЗначение - Результат операции
  </div>

  | Параметр | Описание |
  |---|---|
  | addin_mode | Ручной выбор режима подключения внешней компоненты (для 1С): Изолированно, НеИзолированно |
  | dontwait | Создает фоновое задание и возвращает его данные (только для 1С и OneScript) |

```bsl title="Пример использования для 1С:Предприятие/OneScript"
    URL     = "";
    BindDN  = "cn=admin,dc=example,dc=org";
    Пароль  = "...";
    Таймаут = 30;

    ПараметрыСоединения = OPI_LDAP.СформироватьПараметрыСоединения(URL, BindDN, Пароль, Таймаут);
    Соединение          = OPI_LDAP.ОткрытьСоединение(ПараметрыСоединения);
    DN                  = "cn=OPI Test User,dc=example,dc=org";

    ЗначенияПочты = Новый Массив;
    ЗначенияПочты.Добавить("test@example.org");

    Изменение = Новый Структура;
    Изменение.Вставить("operation", "replace");
    Изменение.Вставить("attribute", "mail");
    Изменение.Вставить("values"   , ЗначенияПочты);

    Изменения = Новый Массив;
    Изменения.Добавить(Изменение);

    Результат = OPI_LDAP.Изменить(Соединение, DN, Изменения);
```
