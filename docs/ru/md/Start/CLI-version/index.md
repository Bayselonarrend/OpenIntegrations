# CLI и интеграция с другими системами

**OInt CLI** — консольное приложение Открытого пакета интеграций. Оно выполняет те же методы, что расширение для 1С и пакет OneScript, и не требует ни платформы, ни интерпретатора: к нему обращаются из терминала, из другой программы и из ИИ-агента.

## Что умеет приложение

- **Командная строка.** Один вызов `oint <библиотека> <метод>` выполняет метод и завершает работу. Так приложение запускают из bat- и sh-скриптов.
- **Сервер STDIO.** Команда `oint server stdio` читает запросы из стандартного ввода и пишет ответы в стандартный вывод. Другая программа держит процесс открытым и обменивается с ним сообщениями, не разбирая аргументы командной строки.
- **HTTP-сервер.** Команда `oint server http` принимает запросы на выбранном порту. Ответ уходит как JSON или, по настройке, как Janx. Для запроса можно включить POST, GET и проверку заголовка `Authorization`.
- **MCP.** Команда `oint mcp start` поднимает сервер [Model Context Protocol](https://modelcontextprotocol.io/) поверх стандартных потоков. Агент получает список библиотек и методов, читает параметры и выполняет вызов. Значения из файла конфигурации подставляются на место имён переменных, поэтому секреты не попадают в контекст агента.

Про вызов из командной строки написано в подразделе [CLI](/docs/Start/CLI-version/cli). Про сервер для агента — в подразделе [MCP](/docs/Start/CLI-version/mcp-server).

## Установка

Файлы текущей версии лежат в [последнем релизе](https://github.com/Bayselonarrend/OpenIntegrations/releases/latest) и на [странице загрузок](/download). На странице загрузок те же команды уже подставлены для выбранного языка и зеркала.

### Windows

Запустите установщик `oint_x.x.x_installer_lang.exe`. Он создаёт каталог программы и добавляет его в `PATH`. После перезагрузки команда `oint` доступна из любого каталога.

### Debian и Ubuntu

Пакет не тянет дополнительные зависимости из сети:

```bash
wget <ссылка на oint_x.x.x_all_ru.deb>
sudo apt install -y ./oint_x.x.x_all_ru.deb
```

### Fedora, RHEL и CentOS

При установке пакет предложит `libicu` — библиотеку ICU, без которой движок приложения не стартует:

```bash
wget <ссылка на oint-x.x.x-1.noarch_ru.rpm>
sudo rpm -i ./oint-x.x.x-1.noarch_ru.rpm
```

### AppImage

Отдельный исполняемый файл для Linux. Установка в систему не нужна:

```bash
wget <ссылка на oint-x.x.x_ru-x86_64.AppImage>
chmod +x ./oint-x.x.x_ru-x86_64.AppImage
./oint-x.x.x_ru-x86_64.AppImage
```

### Пакет OneScript

Пакет `oint-cli` ставится через OPM. Нужен OneScript `2.0.0` или новее и пакет библиотеки `oint` той же версии: консольное приложение зависит от него. Каталог `bin` OneScript должен быть в `PATH`, иначе команда `oint` не найдётся из произвольного каталога.

Из хаба пакетов, русская версия:

```bash
opm install oint-cli
```

Из скачанного файла `oint-cli-x.x.x_lang.ospx`:

```bash
opm install -f "./oint-cli-x.x.x_ru.ospx"
```

Состав файлов каждого варианта и чем они отличаются описаны в разделе [Про варианты релизов](/docs/Start/Release-variants).

## Подразделы

Дальше каждый способ работы разобран отдельно:

- [CLI](/docs/Start/CLI-version/cli) — вызов методов из командной строки, справка, параметры и вывод результата
