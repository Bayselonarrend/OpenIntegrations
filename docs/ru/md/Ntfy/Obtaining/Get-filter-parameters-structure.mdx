# Получить структуру параметров фильтра
 Получает структуру параметров для получения сообщений из топика



<Tabs>
  <TabItem value="params" label="Параметры" default>

`Функция ПолучитьСтруктуруПараметровФильтра(Знач Пустая = Ложь) Экспорт`

  | Параметр | CLI опция | Тип | Обяз. | Назначение |
  |-|-|-|-|-|
  | Пустая | --empty | Булево | &#x2716; | Истина > структура с пустыми значениями, Ложь > в значениях будут описания полей |

  </div>
