# Словарь en.json

`ci/os/internal/Classes/DictionariesMethods.os` (его же вызывает `ci/os/MainProcessingScript.os`) дописывает в `service/dictionaries/en.json` новые русские слова из исходников. Значение нового ключа пустое. Если такие ключи остались, скрипт пишет `Dictionaries contain new words without translation` и завершается с кодом 111. Сборка на этом останавливается.

Менять можно только пустые значения. Ключи, уже заполненные строки и порядок ключей не трогать. Новые ключи не добавлять и не удалять.

## Код и текст

Ключ без пробелов — идентификатор: имя функции, переменной, модуля, метода. Значение тоже без пробелов и в том же регистре, что ключ.

- `ПолучитьЛог` → `GetLog`
- `OPI_ТестыCLI` → `OPI_TestsCLI`
- `ПолучитьURL` → `GetURL`

Пробел, дефис или разбиение PascalCase на слова ломает английский код 1С: замена идёт по строке целиком.

Ключ с пробелами или как фраза — обычный текст (комментарий, сообщение). Пробелы и знаки препинания сохраняются.

- `Получить лог` → `Get log`
- `Не удалось удалить файл` → `Failed to delete file`
- `Создает новое событие` → `Creates a new event`

`OPI_`, `URL`, `XML`, `JSON`, `SQL`, `QR`, `CLI`, `TCP`, `HTTP`, `SSH` остаются слитно с соседней частью имени. Латиница и цифры внутри ключа не переводятся.

## Синтаксис-помощник

Ключ, который является именем метода, свойства, типа или значения перечисления платформы, переводится тем английским именем, которое записано в синтаксис-помощнике. Своё английское слово на это место не ставить: `Найти` в справке — `Find`, `ТаблицаЗначений` — `ValueTable`.

Перед записью такого ключа сверься с MCP `1c-platform` (`search` или `info`, для члена типа — `getMember`). В обычном синтаксис-помощнике английское имя стоит рядом с русским. Та же пара есть в `shcntx_ru.hbk`, и сервер её читает. Если инструмент показал английское имя, значение словаря — оно, буква в букву и без пробелов.

Ответ инструментов версии, которой пользуется Alpaca, сейчас содержит только русское имя: английское при сборке ответа отбрасывается. Пока в тексте ответа английского имени нет, значение этого ключа оставь пустым.
